# Dataset layout

Place the datasets here (or set the environment variable `VS_DATA_ROOT` to a folder with this layout):

```
data/
  SumMe/
    videos/        # *.mp4
    GT/            # *.mat annotation files
  TVSum/
    videos/        # *.mp4
    annotations/
      ydata-tvsum50-anno.tsv
```

The datasets are not included in this repository; download them from their original sources.
